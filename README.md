# נתיב עברית | Nativ Ivrit
**Aprenda hebraico moderno de forma simples, interativa e conectada à cultura judaica.**

## 📖 Sobre o projeto

O **Nativ Ivrit** é um aplicativo educacional desenvolvido para facilitar o aprendizado do hebraico moderno, tornando o processo mais acessível, dinâmico e interessante.

O projeto surgiu com a ideia de aproximar pessoas da língua e da cultura judaica por meio da tecnologia, oferecendo uma experiência de aprendizado interativa, especialmente para jovens e pessoas que desejam conhecer ou aprofundar seus conhecimentos em hebraico.

Além do aprendizado do idioma, o aplicativo busca fortalecer a conexão com a identidade, a história e a cultura judaica.

## 🎯 Objetivo

Criar uma plataforma que ajude os usuários a aprender hebraico de maneira prática, começando pelos conteúdos básicos e avançando gradualmente no conhecimento do idioma.

O aplicativo também procura incentivar o interesse pela língua hebraica, seja por motivos culturais, pessoais, acadêmicos ou por planos futuros de morar em Israel.

## 🚀 Funcionalidades

- **Alfabeto Hebraico:** apresentação das letras, seus nomes e transliterações.
- **Aprendizado Interativo:** atividades para praticar e reforçar o conteúdo aprendido.
- **Trilha de Aprendizado:** organização dos conteúdos em etapas.
- **Exercícios:** atividades para testar os conhecimentos.
- **Interface Intuitiva:** navegação simples e visual agradável.
- **Conteúdo Educacional:** aprendizado progressivo do hebraico moderno.

## 🛠️ Tecnologias utilizadas

- React Native
- JavaScript
- Expo
- Visual Studio Code

## 💡 Nossa proposta

O Nativ Ivrit não é apenas um aplicativo para aprender um novo idioma. É uma iniciativa que utiliza a tecnologia para aproximar pessoas de uma língua que possui grande importância histórica e cultural.

Acreditamos que aprender hebraico pode ser uma maneira de fortalecer conexões, conhecer novas culturas e criar oportunidades para o futuro.

## 👨‍💻 Desenvolvedores

Projeto desenvolvido como trabalho de conclusão, com o objetivo de unir tecnologia, educação e cultura judaica.
